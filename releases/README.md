### Release Highlights
- Intelligent Safaricom SakaHub knowledge base synchronizer and RAG copilot widget.
- Streamlined permissions model: zero intrusive background alarms or cookie permissions.
- Non-blocking staleness check triggered on assistant activation.
- Robust handling of SakaHub session states with friendly portal connection guidance.
- Adaptive W3C Chrome text fragment highlights directly inside SakaHub articles.
